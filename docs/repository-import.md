# Repository Import

This repository starts with a fresh Git history under IAB Tech Lab ownership.
The project name, crate names, commands, configuration namespaces and document
paths use Auctioneer throughout. No compatibility aliases are provided.

Historical plans, reviews and measurements are retained for context. Their
names and paths have been updated for this repository. Measurements describe
the historical artifacts that produced them, not a qualification of the
renamed executables. Local integrity checksums are updated when renamed
content changes; upstream source revisions, source hashes, licenses and
unchanged captures retain their original provenance.

Fresh artifact qualification requires an initial repository commit and new
measurements. Historical commit identifiers are archival references, not
commits imported into this repository.
