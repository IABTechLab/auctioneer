# M5 User Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement bounded, privacy-enforced user-sync endpoints through the existing EdgeZero application on all four adapters.

**Architecture:** Keep cookie, catalog, selection, template, and wire logic in focused `auctioneer-core::usersync` modules; replace the permissive sync API in `auctioneer-privacy` with concrete endpoint-specific decisions. Add thin manifest-declared `#[action]` handlers using the existing configuration, admission, and response-completion path. No new workspace crate or adapter-specific router.

**Tech Stack:** Rust 1.95.0, existing serde/serde_json/time/url tooling, pinned EdgeZero `491df844a0f06924de88000b244329a141debf5a`, shared bounded parsing and privacy modules, native tests and existing WASM targets. Qualify cookie/base64 dependencies before introducing them.

**Design:** [M5 user-sync design](../specs/2026-09-30-m5-usersync-design.md), the sync portions of the [master design](../specs/2026-05-21-auctioneer-openrtb-server-design.md), and the existing [M4 design](../specs/2026-09-26-m4-privacy-design.md).
