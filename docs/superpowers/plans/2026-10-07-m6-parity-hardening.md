**Goal:** Enable bounded, unconditionally sanitized auction debug; finish the initial-scope config/parity acceptance; deliver complete native Q2-A/B/C and reusable Q2-E; and prepare the offline provider harness/artifact handoff/refusal tests and runbooks for M7.6 live execution.

**Tech Stack:** Rust 1.98.1, serde/serde_json, existing bounded JSON and capped-writer APIs, EdgeZero generated App and CLI, Cargo unit/integration/allocation/compile-fail tests, CLI-local Rust process/HTTP qualification harnesses.
