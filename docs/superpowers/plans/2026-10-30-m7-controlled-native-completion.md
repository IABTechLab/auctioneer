# M7 Controlled Native Completion Plan

> Execute the approved native amendment using the existing M7 worktree and
> ordinary modules. Preserve all independent source and behavioral oracles.

Design: [controlled native delivery](../specs/2026-10-30-m7-controlled-native-completion-design.md).

1. Reconcile current spec/plan/roadmap/ISSUES boundaries with AG's approval.
   Keep completed resource-model preparation, but move complete certification
   to R0 rather than adding new private-engine proof surfaces inside M7.
2. Add declarative native-only publication, default activation and compiled
   alias ancestry to existing metadata/discovery. Prove consistent native/guest
   filtering and immutable/base vetoes with synthetic controls.
3. Generate native schema dispatch through existing compilation/discovery.
   Install the frozen residency/startup/scratch reservations on native boot,
   prewarm patterns, and enforce bounded post-privacy parameter validation with
   per-auction work/deadline accounting and caller-owned caches.
4. Finish sealed source/candidate response decoding with the shared monotonic
   receipt, exact error scopes, valid siblings and existing allocation charges.
   Preserve standard parsing and expose no arbitrary deserializer/raw body API.
5. Publish the reviewed native priority definitions with runtime opt-in and
   source provenance. Keep guest publications unchanged and run bidder-local
   protocol/schema/allocation conformance without relaxing frozen requirements.
6. Implement real 14-flow generated-App onboarding, independent activation,
   privacy, invalid-param, missing-secret/settings, alias-base and signed-sync
   controls. Document an executable native configuration handoff.
7. Wire actual evidence producers and CI acceptance. Run native accounting,
   allocation/stress, secure/feature and guest nonactivation/build regressions.
   Report native acceptance separately from unproven R0/provider readiness.
8. Review complete changes, update only genuinely resolved issues, commit and
   push verified rounds. Do not mark M7 complete before all required native
   flows and producer operations pass.
